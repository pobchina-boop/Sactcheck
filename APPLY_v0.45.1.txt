SACTCheck v0.45.1 drop-in update

1. Extract the ZIP.
2. Select everything inside the extracted folder.
3. Drag the selected files and folders into the main Sactcheck repository folder.
4. Choose “Replace the files in the destination”.
5. Open GitHub Desktop, review the changes and commit them.

This hotfix is intended to be applied over SACTCheck v0.45.0.
