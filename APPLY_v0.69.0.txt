SACTCheck v0.69.0 — Sustainability Module

DRAG-AND-DROP UPDATE

Baseline: current GitHub main / v0.68.0.

1. Extract SACTCheck_v0.69.0_drag_and_drop.zip.
2. Open the extracted folder.
3. Select all files/folders inside it.
4. Drag them into the root of your existing SACTCheck project.
5. Choose Replace files in the destination when prompted.
6. Open the project with Live Server and hard refresh (Ctrl+F5).
7. Confirm a Sustainability button appears in the main hero and on active regimen cards.
8. Open Sustainability from a regimen card and confirm the regimen context is carried into the page.

This update replaces js/library-ux.js and adds sustainability.html plus release documentation. It does not replace protocol JSON files or clinical rule-engine files.
