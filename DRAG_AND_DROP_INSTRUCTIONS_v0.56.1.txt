SACTCheck v0.56.1 installation

This is a cumulative repository package. It contains every v0.56.0, v0.55.0 and v0.54.0 change.

1. Extract the downloaded ZIP.
2. Open the folder Sactcheck_v0.56.1_FULL.
3. Select everything inside that folder.
4. Drag the selected contents into your existing Sactcheck repository folder.
5. Choose Replace the files in the destination and allow folders to merge.
6. Do not copy the outer Sactcheck_v0.56.1_FULL folder into the repository as a nested directory.
7. Review the changes in GitHub Desktop.
8. Use the commit summary and description in GITHUB_COMMIT_v0.56.1.txt.
9. Commit and push.
10. Confirm that the GitHub Pages deployment workflow completes successfully.
11. Test the live Clinical scenario interpreter and the five detailed Regimen info pages.
