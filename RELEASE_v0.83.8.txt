BUILD NOTES
Authored JSON and generated HTML/PDF files are included. Routine HTML parity:
  npm run patient:build-suite
  npm run test:breast-next

PDF generation/verification needs Python with WeasyPrint, PyMuPDF, Pillow and
zxing-cpp. From the repo root:
  python tools/build-breast-v0838-pdfs.py
  python tools/verify-breast-pdfs-v0838.py
After intentionally regenerating protected PDFs, review and refresh the protected
asset hashes before running the release gate. PDF binaries may vary with renderer
versions; patient HTML and the clinical sources remain the authored reference.

The reconciliation/content Python files are authoring tools, not normal build
steps. Re-running reconciliation resets validation flags until tests are rerun.
When rebuilding content from the authoring tools, run the monitoring refinement
after the content builder. SACT_SOURCE_PDF_DIR can point to locally downloaded
official source PDFs; otherwise the recorded source hashes are retained.
