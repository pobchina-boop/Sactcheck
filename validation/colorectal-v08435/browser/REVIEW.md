# v35 browser review

Manual desktop review opened all ten patient portals and all ten full OncoWiki references at a 1363-pixel viewport. All reference disclosure groups expanded; the rendered pages had one rich anatomy map each, seven cards for pembrolizumab and eight for the other regimens. No broken images or horizontal document overflow were observed. Fruquintinib portal and panitumumab/FOLFIRI anatomy and consent were visually inspected; the portal consent link reached the correct regimen form.

This is partial desktop evidence. Automated Chromium launch failed before any of the 80 planned states ran (socket EPERM). Mobile widths, clinician assessment UI examples, complete console/network coverage, real-device installation/camera/printing and canonical deployment remain unverified. Engine tests and PDF inspection are separate evidence and do not substitute for these missing browser checks.
