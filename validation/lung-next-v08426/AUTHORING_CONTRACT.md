- Targeted patient symptoms can be strings supported by targeted renderer; verify it. Standard cytotoxic renderer supports a fixed symptom list in tools/build-complete-pathways.cjs; use those exact keys. Oral adherence/food/interactions/missed or vomited dose instructions must be medicine specific. No invented universal prescription. Include pregnancy/fertility information where sourced.

- Use new source-audited action pathways with explicit drug components so the real dose renderer carries the action through. Test conservative handling of multiple concurrent limitations and withheld treatment.
