COMMIT SUMMARY
feat(protocols): reconcile organ-function rules across the partial library

COMMIT DESCRIPTION
Completes the v0.58.1 organ-function remediation programme across all 74 records previously marked as partially rule-encoded.

Adds structured, component-specific renal and hepatic inputs and decision pathways to 70 protocols, while explicitly documenting four mapped protocols whose source provides no prescriptive organ-function dose-adjustment table. No artificial renal or hepatic cutoff is introduced for those records.

Adds 299 executable organ-function rules covering protocol-specific CrCl/GFR bands, dialysis, bilirubin, transaminases, Child–Pugh class, qualitative impairment and treatment-emergent organ toxicity where supported by the mapped source. All new inputs remain optional and preserve single-value partial assessment, with omitted domains shown as unassessed.

Adds a 74-record source register, library-wide reconciliation audit, SHA-256 protocol integrity register, idempotent reconciliation tooling and regression coverage proving that all 299 new rules can be triggered through the production assessment engine.

Updates the application to v0.59.0 and preserves the search-first interface, collapsed early-development Clinical Scenario Interpreter and cumulative ten-regimen knowledge base. Independent consultant oncology and oncology-pharmacy validation remains pending; the current official NCCP protocol and local governance remain authoritative.
