SACTCheck v0.41.0 — update instructions

1. Extract the ZIP.
2. Replace the existing repository/application contents with the extracted Sactcheck folder contents.
3. Commit all changed and newly added files, including protocol JSON, data, JavaScript, tests and release documentation.
4. Push to the branch used by GitHub Pages.
5. Wait for GitHub Pages deployment to complete.
6. Hard-refresh the browser or clear the installed PWA/site cache if the previous version remains visible.
7. Confirm the home badge reads “Version 0.41.0 · complete sarcoma library”.
8. Select Sarcoma and verify that 25 regimen cards are available.
9. Open representative protocols such as MAP, IE–VAC, doxorubicin/ifosfamide, imatinib and trabectedin and test one-value partial assessments.

Do not delete the official NCCP PDF links or central supportive-care assets. This remains a decision-support prototype; verify all clinical decisions against the current official NCCP source and local policy.
