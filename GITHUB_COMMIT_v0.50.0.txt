Expand Haematology with Multiple Myeloma core and blood-red redesign (v0.50.0)

Description:
Introduces the SACTCheck v0.50.0 Multiple Myeloma Core release. Replaces the muted burgundy Haematology palette with a higher-contrast blood-red visual system and expands the plasma-cell library from five to fifteen source-linked NCCP protocols. Adds CyBorD, daratumumab, lenalidomide, pomalidomide, PVD, RVD-Lite and Dara-Rd pathways, plus an oral-only route filter. Preserves all 361 existing solid-tumour protocol JSON files unchanged. Haematology clinical and pharmacy validation remains pending.
