SACTCheck v0.63.0 application instructions

1. Replace the current project files with the v0.63.0 full project or apply the drop in package.
2. Deploy the updated static site.
3. Open SACTCheck and select Validation workspace.
4. Enter the reviewer name and role.
5. Select one tissue and review regimens sequentially against the current NCCP source.
6. Export the full validation log after each review session.
7. Keep exported validation logs in the project validation record until formal specialist validation is complete.
