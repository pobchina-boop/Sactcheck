SACTCheck regimen-card metadata drop-in update v1.0.1
====================================================

1. Keep the dated SACTCheck backup ZIP already created.
2. Open this extracted update folder.
3. Select ALL files and folders INSIDE this folder.
4. Drag them into the main Sactcheck repository folder—the folder containing index.html, package.json, protocols, js, css and data.
5. Choose "Replace the files in the destination" when Windows asks.
6. Do not drag the outer SACTCheck_regimen_metadata_DROP_IN_v1.0.1 folder itself into Sactcheck.
7. Open GitHub Desktop. The changed files should appear under Changes.
8. Preview SACTCheck and confirm cards show metadata such as:
   Advanced disease · q21d
   Adjuvant · 6 cycles · q21d

The update does not change protocol decision rules. It generates card metadata only from the published protocols/index.json library. Unresolved duration or intent values are omitted rather than guessed. REGIMEN_CARD_METADATA_REVIEW.csv lists items needing later source review.
