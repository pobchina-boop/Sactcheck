SACTCheck v0.45.2 drag-and-replace update

1. Extract SACTCheck_v0.45.2_ONE_PAGE_OUTPUT_DROP_IN.zip.
2. Select everything INSIDE the extracted folder.
3. Drag the selected files and folders into the main Sactcheck repository folder.
4. Choose "Replace the files in the destination" when Windows asks.
5. Restart Live Server and refresh the browser with Ctrl+F5.
6. Confirm the library badge reads Version 0.45.2.
7. Run an assessment and use "Print / save one-page PDF" in the result section.

Do not drag the outer update folder into Sactcheck, as this would create an unwanted nested folder.
