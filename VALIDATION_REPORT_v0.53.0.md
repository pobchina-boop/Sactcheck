# Validation Report — SACTCheck v0.53.0

## Scope

Validation covers the new immunotherapy visual safety panel, its restriction to immune-checkpoint inhibitor protocols, linkage to existing inputs, status derivation from deterministic assessment findings, official source navigation and preservation of all clinical protocol files.

## Functional tests

The focused v0.53.0 regression test confirms:

- package and module version 0.53.0;
- correct CSS and JavaScript integration;
- presence of the in-engine **Immune safety** control and panel;
- nine organ-system domains;
- support for a pembrolizumab protocol;
- exclusion of a non-immunotherapy AC protocol;
- direct links to NCCP, ESMO, SITC and relevant EMA product information;
- linkage of TSH, free T4, cortisol and glucose fields to the endocrine tile;
- Grade 2 pneumonitis produces a lung **Review / withhold** state;
- an entered TSH value without a restrictive finding produces **Data entered**, not a false warning;
- Grade 4 pneumonitis produces an **Urgent / stop** state.

## Library audit

The repeatable audit command is:

```text
npm run audit:immune-safety
```

The audit outputs CSV and Markdown reports and confirms:

- 49 supported ICI protocols;
- 9 organ systems;
- agent recognition across pembrolizumab, nivolumab, ipilimumab, atezolizumab, durvalumab, tislelizumab, dostarlimab, tremelimumab, avelumab, cemiplimab and serplulimab protocols represented in the current catalogue;
- structured linked inputs across endocrine, renal, hepatic, lung, bowel, skin, neurological, cardiac/muscle and infusion/systemic domains;
- zero intentional protocol JSON changes.

## Deterministic safety boundary

The panel does not infer a management action from colour alone. Status is generated by this order:

1. existing restrictive assessment finding;
2. entered structured data without a restrictive finding;
3. no data entered.

A critical or review state therefore requires an existing encoded assessment finding. The panel cannot turn a normal isolated value into complete treatment clearance, and missing domains remain unassessed.

## Clinical governance

This technical validation does not constitute independent clinical validation of every immunotherapy rule. Independent Consultant Oncology and oncology-pharmacy review remains required. The current official NCCP regimen, local immune-toxicity pathway and current product information remain authoritative.
