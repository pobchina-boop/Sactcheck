SACTCheck v0.67.0 knowledge base update

Preferred update method
1. Use the full project ZIP for the normal repository replacement workflow.
2. If applying the smaller update manually, copy the contents of the drop in ZIP over the existing Sactcheck project while preserving folders.
3. Commit the supplied source changes.
4. Deploy using the established SACTCheck workflow.
5. Confirm that the application displays v0.67.0 and that the three new knowledge profiles open correctly.

This release does not change any clinical protocol JSON rule, threshold, treatment action, organ function pathway, schedule or clinical input definition.
