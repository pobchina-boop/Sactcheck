COMMIT SUMMARY
feat(knowledge-base): add five detailed regimen profiles

COMMIT DESCRIPTION
Expands the cumulative SACTCheck regimen knowledge base from ten to fifteen full profiles.

Adds structured knowledge modules for FOLFIRI, carboplatin plus paclitaxel in gynaecological cancer, pembrolizumab plus paclitaxel and carboplatin for metastatic squamous NSCLC, sacituzumab govitecan for previously treated metastatic triple-negative breast cancer, and durvalumab plus gemcitabine and cisplatin for advanced biliary tract cancer.

Each profile includes treatment setting and intent, component mechanisms, patient-selection orientation, supportive care, baseline and interval monitoring, priority toxicities, urgent-review signals, administration workflow, primary evidence, key outcomes, limitations, publication links, source-check date and reviewer status.

Adds or enriches V303, GOG-158, KEYNOTE-407, ASCENT and TOPAZ-1 evidence mappings and adds a reusable sacituzumab-govitecan medicine profile. Trial-to-protocol differences are explicitly documented, including shared multi-indication protocols and the expired stated review date on the current NCCP 00897 v3 PDF.

Updates the knowledge module and interface version to v0.60.0 while preserving the search-first homepage, collapsed early-development Clinical Scenario Interpreter, v0.59.0 organ-function reconciliation and all deterministic assessment behaviour.

All 382 protocol JSON files remain byte-for-byte unchanged from v0.59.0. The five profiles remain drafts pending independent consultant oncology and oncology-pharmacy review; current NCCP protocols and local governance remain authoritative.
