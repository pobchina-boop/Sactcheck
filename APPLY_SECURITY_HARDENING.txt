SACTCheck GitHub security hardening — apply by drag and replace

1. Extract this ZIP.
2. Select everything inside the extracted folder, including the .github folder.
3. Drag the selected contents into the main Sactcheck repository folder.
4. Choose Replace the files in the destination.
5. Open GitHub Desktop and review the changed files.
6. Commit the update to a new branch rather than directly to main.
7. Push the branch and open a pull request.
8. Follow GITHUB_SECURITY_HARDENING_GUIDE.md to restrict Actions, protect main and enable the repository security features.

Important: the update deliberately overwrites the old .github/workflows/protocol-library.yml file with a disabled read-only placeholder. This prevents the previous workflow from automatically committing and pushing generated files.
