SUMMARY
Fix stale consent runtime loading in v0.71.2

DESCRIPTION
- Fixes a bootstrap/cache issue that could leave v0.71.1 consent code active after applying v0.71.2.
- Updates the consent loader to request the v0.71.2 builder with a new cache key.
- Detects and replaces an older consent-builder runtime already present in the browser page.
- Prevents the v0.71.2 builder from reusing an older consent PDF exporter left in an open tab.
- Ensures newly generated consent PDFs use the v0.71.2 schedule and immunotherapy hardening.
- Adds a regression test preventing the loader from being pinned again to the old consent runtime.
- Makes no change to protocol JSON or deterministic clinical assessment rules.
