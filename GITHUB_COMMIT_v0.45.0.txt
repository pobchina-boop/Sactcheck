Summary

Complete Skin and Melanoma protocol library and release v0.45.0

Description

- Completed the current NCCP Skin/Melanoma SACT catalogue with 16 unique regimens.
- Added 9 new canonical protocol files and reconciled 7 existing/shared protocols without duplicate cards.
- Added melanoma, Merkel-cell carcinoma, cutaneous squamous-cell carcinoma and basal-cell carcinoma pathways.
- Added BRAF/MEK molecular eligibility and source-specific cardiac, ocular, pyrexia, CK, blood-pressure and respiratory safety assessment.
- Added exact dacarbazine haematology thresholds, renal dose bands and high-emetogenic supportive-care mapping.
- Added ipilimumab and nivolumab/ipilimumab immune-toxicity and phased-course pathways.
- Added advanced, adjuvant and perioperative melanoma card contexts for nivolumab and pembrolizumab.
- Corrected pembrolizumab 400 mg cycle metadata to q42d.
- Preserved optional immunotherapy endocrine inputs and single-value partial assessment.
- Expanded the full indexed SACTCheck library to 338 protocols.
- Added Skin/Melanoma catalogue validation, source register, audit and regression tests.
- Updated the application version to v0.45.0.
