SACTCheck v0.61.0 application instructions

Preferred method
1. Use the full-project ZIP as the repository replacement baseline.
2. Copy the contained Sactcheck directory into the working repository.
3. Review the changed files, run npm test, and commit using GITHUB_COMMIT_v0.61.0.txt.
4. Deploy through the existing GitHub Pages workflow.

Drop-in method
1. Extract the drop-in ZIP over an existing v0.60.3 repository.
2. Preserve the directory structure and allow replacement of matching files.
3. Run npm test, npm run security:check, npm run build:pages and npm run security:site.

No protocol JSON files are changed by this release.
