SACTCheck v0.58.1 — application instructions

FULL PROJECT
1. Extract SACTCheck_v0.58.1_full_project.zip.
2. Replace the contents of your local Sactcheck repository with the extracted Sactcheck folder contents.
3. Review the changed files, then commit and push through the usual GitHub workflow.

DROP-IN UPDATE
1. Extract SACTCheck_v0.58.1_drop_in.zip.
2. Copy the contained Sactcheck folder over the existing repository root and allow matching files to be replaced.
3. Do not delete unrelated repository files.

VALIDATION
From the repository root, run:
  npm test
  npm run security:check
  npm run audit:organ-function
  npm run build:pages
  npm run security:site

SAFETY
NCCP 00450 and 00451 are source-reconciled but remain pending consultant oncology and oncology-pharmacy validation. The official current NCCP PDF and local governance remain authoritative.
