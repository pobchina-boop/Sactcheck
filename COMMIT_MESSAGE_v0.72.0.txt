SUMMARY
Add regimen-driven clinic workflow engine

DESCRIPTION
- Introduces the SACTCheck Regimen Workflow Engine as a separate layer from the deterministic clinical assessment engine.
- Makes the selected regimen the central object for generating and surfacing clinic workflow modules.
- Adds a new Clinic workflow action to regimen cards.
- Integrates the existing structured assessment and v0.71.3 regimen-specific consent into one workflow panel.
- Adds current NCCP V8 regimen-derived antiemetic prescribing support for high, AC high-risk, carboplatin AUC >=4 / trastuzumab deruxtecan high-risk, moderate, low and minimal emetogenic pathways.
- Opens supportive-care prescribing support as a one-page browser PDF rather than automatically downloading it.
- Uses current NCCP V8 antiemetic content rather than copying the older 2021 CUH medication lists unchanged.
- Adds a conservative supportive-care interaction override framework, seeded with an erlotinib/PPI interaction warning from current product information.
- Adds regimen-derived extravasation classification and drug-specific compress/antidote guidance using NCCP classification and 2023 management guidance.
- Keeps extravasation output explicitly subordinate to local policy and clinician judgement.
- Establishes a planned Patient Regimen Hub / QR workflow module for the next development phase.
- Refreshes the homepage mission to "SACT support at the point of care" and "One regimen. One clinical workflow."
- Updates the visual workflow to Assess / Consent / Support / Inform and integrates the existing SACTCheck logo mark.
- Removes the currently unused add-regimen / protocol-import control from the clinician-facing interface.
- Adds focused regression tests for workflow resolution, supportive-care PDF generation and UI integration.
- Makes no change to protocol JSON, treatment thresholds, eligibility rules, dose actions or other deterministic clinical assessment logic.
