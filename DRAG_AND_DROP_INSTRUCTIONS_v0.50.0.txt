===============================================

1. Extract the ZIP fully.
2. Open the extracted folder named Sactcheck_v0.50.0_FULL.
3. Select everything inside that folder (Ctrl+A).
4. Drag the selected contents into your existing local Sactcheck repository folder.
5. Choose Replace the files in the destination and allow folders to merge.
6. Open GitHub Desktop, review the changes, commit and push.

Do not drag the outer Sactcheck_v0.50.0_FULL folder itself into the repository.
