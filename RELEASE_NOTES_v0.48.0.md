# SACTCheck v0.48.0 — Feasibility study release

## Purpose
This release prepares SACTCheck for controlled distribution to oncology clinicians completing hypothetical-scenario feasibility and usability testing. It changes presentation, onboarding and study support only; protocol JSON files and clinical rules are unchanged.

## Changes
- Added the approved shield, protocol-document and check-mark visual identity.
- Added scalable logo assets, favicon, Apple home-screen icon, Android/PWA icons and a web-app manifest.
- Rebuilt the application header as a consistent branded product header.
- Added a polished study landing panel explaining purpose, scope and library coverage.
- Added first-use study onboarding with an accessible modal and persistent study-information control.
- Reframed the top notice as a feasibility-evaluation boundary rather than developer-oriented prototype text.
- Added a standalone quick-start guide, feedback-form template and tester-invitation text.
- Added responsive visual refinements to search, tumour navigation, regimen cards and assessment outputs.
- Added a recorded follow-up task to embed a 60–120 second walkthrough video after it is supplied.
- Updated the application version to v0.48.0.

## Safety boundary
Use hypothetical, non-identifiable scenarios only. SACTCheck does not prescribe, authorise or confirm treatment safety. Verify the current official NCCP protocol and apply complete clinical assessment, local policy and independent oncology judgement.
