Commit summary

feat(tracker): add NCCP source change surveillance

Commit description

Introduces the SACTCheck NCCP Change Tracker across all 376 enabled protocols in the active application index.

Adds a canonical source register with NCCP code, version, title, tumour group, official source address, SACTCheck encoding version, source identity fingerprint and protocol JSON fingerprint. The first scheduled repository scan captures PDF and extracted text fingerprints for future comparison.

Adds detection for new catalogue sources, updated versions or source addresses, silent PDF replacements and removed or moved source candidates. Adds initial clinical significance triage for possible treatment criteria, safety workflow, information and formatting changes.

Adds a dedicated What is New and What Has Changed dashboard with source summary cards, remote scan state, change filters, previous and current source comparison, a searchable source register and an explanation of the function and strength of every tracker capability.

Adds per regimen source status to the generic assessment screen and provides direct access to the relevant source register record.

Adds a weekly and manually triggered GitHub workflow that scans configured NCCP catalogue pages, captures PDF and extracted text fingerprints, generates a change report, runs regression tests and opens a pull request when tracked source data changes.

Preserves a mandatory human review gate. No detected source change can automatically rewrite a clinical rule, protocol threshold, dose action, knowledge profile or supportive care pathway.

Adds focused comparison tests, source register validation, release documentation and a protocol integrity register. All 382 protocol JSON assets remain unchanged from v0.61.0.
