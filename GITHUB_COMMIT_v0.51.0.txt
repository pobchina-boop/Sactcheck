COMMIT SUMMARY

Reconcile the full Solid Tumour catalogue and standardise partial assessment (v0.51.0)

COMMIT DESCRIPTION

Introduces SACTCheck v0.51.0 “Solid Tumour Reconciliation,” establishing a reproducible structural and source-metadata baseline for all 361 indexed Solid Tumour protocols.

Changes include:

- Reconciles 361 unique Solid Tumour protocol files within the 376 protocol catalogue
- Distinguishes unique protocol files from tumour-site placements for shared regimens
- Confirms no duplicate protocol IDs, NCCP codes, indexed paths or official source URLs
- Removes a stale unindexed nested protocol copy
- Replaces 12 non-specific “current” source-version labels with explicit versions from current official NCCP PDFs
- Corrects the direct official PDF addresses for NCCP 00206 and 00376
- Standardises optional single-value assessment across all Solid Tumour protocols
- Removes forced assessment-launch requirements while retaining formerly required context fields as visible optional inputs
- Adds reproducible JSON, CSV and Markdown reconciliation reports
- Adds library-wide single-value and numeric threshold-boundary regression tests
- Preserves all encoded rule conditions, treatment thresholds, dose-modification recommendations and Haematology protocol JSON files unchanged

The release contains 5,879 Solid Tumour input definitions and 5,577 encoded rules. All 361 Solid Tumour protocols passed a single-value assessment check, and 6,162 numeric rule boundaries were tested.

Structural reconciliation does not constitute independent clinical validation. Protocol-level Consultant Oncology and oncology-pharmacy review remains required, and the current official NCCP regimen remains authoritative.
