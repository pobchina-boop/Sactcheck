# SACTCheck v0.69.2 — Engine-First Homepage Refinement

## Purpose
Clarify the homepage around SACTCheck's primary clinical job: finding an NCCP regimen and starting a transparent protocol assessment.

## Changed
- Promotes the live regimen search into the main above-the-fold hero so the assessment engine is immediately usable on page open.
- Reframes the hero around the four-step workflow: Find → Assess → Explain → Verify.
- Retains the Solid Tumour SACT and Haematology SACT cards directly beneath the primary engine workflow.
- Moves NCCP Change Tracker, Clinical validation, Knowledge & evidence and Sustainability into a compact supporting-tools card shelf.
- Keeps NCCP source status visible in the header while reducing competing homepage calls to action.
- Hides the Clinical Scenario Interpreter from mainstream navigation while retaining the underlying feature for internal testing via `?experimental=1`.
- Tightens alignment, spacing, responsive behaviour and button hierarchy.

## Safety / governance
- No NCCP protocol JSON changed.
- No deterministic assessment rule, threshold, dose action or clinical status logic changed.
- No knowledge-base evidence content changed.
- No Sustainability evidence or regimen metadata changed.
- Existing NCCP Change Tracker and Clinical Validation functionality is preserved.
