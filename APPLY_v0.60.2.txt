SACTCheck v0.60.2 — application instructions

Full-project update
1. Extract SACTCheck_v0.60.2_full_project.zip.
2. Replace the existing repository contents with the extracted Sactcheck folder.
3. Commit and push the replacement files through the established GitHub workflow.

Drop-in update
1. Extract SACTCheck_v0.60.2_drop_in.zip.
2. Copy all enclosed files into the root of the current SACTCheck repository, preserving folder paths.
3. Replace files when prompted.
4. Commit and push using the supplied summary and description.

The release is cumulative and expects v0.60.1 as its immediate baseline. It does not modify protocol JSON files.
