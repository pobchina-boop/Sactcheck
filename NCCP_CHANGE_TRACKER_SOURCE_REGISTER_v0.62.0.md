# NCCP Change Tracker source register summary

## Register scope

The v0.62.0 source register contains 376 enabled protocols from `protocols/index.json`.

Every registered protocol has an official source address in its encoded metadata.

The full machine readable register is stored at:

`data/nccp-change-tracker/source-register-v0620.json`

The national catalogue address is also retained in the configuration.

## Surveillance boundary

The online NCCP catalogue is treated as a surveillance source rather than proof that every possible national regimen is online.

A missing item is therefore flagged for review and is not automatically retired.
