SACTCheck v0.48.2 application instructions

1. In GitHub Desktop, switch to main and pull the latest changes.
2. Create a feature branch named: v0.48.2-ctcae-haematology
3. Extract the drop-in ZIP.
4. Copy everything inside the extracted folder into the main Sactcheck repository folder.
5. Choose Replace the files in the destination.
6. Commit the changes on the feature branch.
7. Publish/push the branch.
8. Open a pull request into main.
9. Wait for Validate and test and CodeQL JavaScript analysis to pass.
10. Merge the pull request. GitHub Pages will deploy the update to sactcheck.com.

This update does not modify protocol JSON files or clinical decision rules.
