SACTCheck v0.50.3 drag and drop update

1. Extract the ZIP.
2. Open the Sactcheck_v0.50.3_FULL folder.
3. Select everything inside the folder.
4. Drag the selected contents into the existing Sactcheck repository folder.
5. Choose Replace the files in the destination and allow folders to merge.
6. Review the changes in GitHub Desktop, commit and push.

Do not copy the outer Sactcheck_v0.50.3_FULL folder into the repository. Copy its contents.
