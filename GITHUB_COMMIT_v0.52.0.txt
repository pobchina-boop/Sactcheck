Commit summary

Add embedded Protocol Dose & Schedule workspace (v0.52.0)

Commit description

Introduces SACTCheck v0.52.0 with an embedded Protocol Dose & Schedule workspace inside the opened regimen assessment engine.

Changes include:

- Adds a Dose & Schedule button beside the official NCCP protocol control
- Displays protocol components, standard doses, routes, treatment days, cycle length and course information
- Adds treatment-phase and scheduled-day selectors where structured source data are available
- Adds selectable protocol-defined dose levels without calculating a patient-specific dose
- Displays source-linked encoded hold, omit, reduction, restart and discontinuation pathways
- Provides structured schedule coverage for 328 of 376 protocols
- Provides selectable dose-level groups for 30 protocols
- Exposes encoded modification pathways for 365 protocols
- Hides the control for 48 protocols that do not yet have sufficiently structured schedule metadata
- Adds reusable JSON, CSV and Markdown coverage reports
- Adds release-specific regression testing and a reusable dose-schedule audit command

This release does not calculate BSA, renal function, carboplatin dose or a final prescribed dose. It does not link to an external calculator. Selecting a dose level changes only the protocol information displayed and does not alter the assessment.

All clinical protocol JSON files remain unchanged from v0.51.0. No treatment thresholds, rule conditions, dose recommendations or assessment outputs were modified.

The current official NCCP protocol and authorised prescribing system remain authoritative. Independent Consultant Oncology and oncology-pharmacy validation remains required.
