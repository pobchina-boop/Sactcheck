SACTCheck v0.58.0 deployment

Usual full-project workflow:
1. Extract SACTCheck_v0.58.0_full_project.zip.
2. Replace the repository contents with the contents of the Sactcheck folder.
3. Commit to main using COMMIT_MESSAGE_v0.58.0.txt.
4. Push and allow GitHub Pages to rebuild.
5. Hard-refresh the browser or reopen the installed home-screen application.

The drop-in ZIP contains only files added or changed by v0.58.0.
