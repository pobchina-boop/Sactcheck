Commit summary

Add an organ-system immunotherapy safety map to ICI regimens (v0.53.0)

Commit description

Introduces SACTCheck v0.53.0 with an original, source-linked immunotherapy visual safety panel inside the opened regimen assessment engine.

Changes include:

- Adds an Immune safety control only to supported immune-checkpoint inhibitor regimens
- Adds nine visual organ-system domains: Lung, Bowel, Liver, Endocrine, Kidney, Skin, Neurological, Cardiac/muscle and Infusion/systemic
- Links each organ tile to existing regimen-specific symptoms, toxicity grades and associated laboratory inputs
- Reuses entered assessment values and deterministic assessment findings rather than creating a parallel toxicity algorithm
- Adds four transparent tile states: No data, Data entered, Review/withhold and Urgent/stop
- Opens the highest-priority triggered organ domain after assessment
- Adds direct navigation back to a relevant assessment input
- Adds source access to the current NCCP protocol, ESMO immunotherapy-toxicity guidance, SITC immune-related adverse-event guidance and relevant EMA product information
- Adds a repeatable immunotherapy coverage audit and focused regression testing
- Provides visual safety coverage for 49 ICI protocols across the current catalogue
- Uses an original SACTCheck tile and icon system rather than reproducing the pharmaceutical educational poster

This release does not add new clinical management rules, diagnose an immune-related adverse event, calculate a patient-specific dose or replace local immune-toxicity guidance. Restrictive status colours appear only when the existing deterministic assessment engine returns a corresponding encoded finding.

All clinical protocol JSON files remain byte-for-byte unchanged from v0.52.5. No NCCP thresholds, rule conditions, recommendations or dose calculations were modified.

The complete security, protocol-publishing, historical regression, GitHub Pages-build and deployable-site validation pipeline passed. Independent Consultant Oncology and oncology-pharmacy validation remains required.
