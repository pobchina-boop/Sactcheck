Commit summary

Add a global clinical scenario interpreter with cumulative v0.54.0 features (v0.55.0)

Commit description

Introduces SACTCheck v0.55.0 with a standalone Clinical scenario interpreter on the main regimen-library screen.

Changes include:

- Adds a regimen-agnostic scenario entry point outside individual protocols
- Accepts de-identified free-text oncology scenarios
- Searches the locally loaded SACTCheck catalogue without an external model or network service
- Recognises controlled tumour, regimen, drug, trade-name, acronym and NCCP-number language
- Ranks and displays possible NCCP protocol matches
- Shows which scenario terms matched each candidate protocol
- Flags medicines mentioned in the scenario that are not represented in a candidate protocol
- Explicitly identifies when no single protocol matches every medicine mentioned
- Requires the clinician to select and confirm the exact regimen before any structured extraction or assessment
- Blocks progression when possible patient-identifiable information is detected
- Transfers the original scenario into the existing in-regimen interpreter only after protocol selection
- Preserves clinician confirmation of every extracted value
- Preserves the deterministic SACTCheck engine as the sole source of the encoded protocol result
- Adds a repeatable catalogue-matching audit across all 376 indexed protocols

This is a cumulative release and includes all v0.54.0 functionality:

- In-regimen constrained scenario interpretation
- Local extraction of common laboratory, toxicity, ECOG, cycle and dose-level fields
- Apply confirmed values and Apply and assess workflows
- Identifier and regimen-context warnings
- Immunotherapy toxicity map copy refinement
- Reliable organ-specific navigation to relevant assessment inputs
- Non-directive decision-support wording

The release does not diagnose, prescribe, clear treatment, silently select an ambiguous regimen, combine rules across protocols or calculate a patient-specific final dose. Scenario text is not transmitted to an external AI service.

All 382 protocol JSON files remain byte-for-byte unchanged from v0.54.0. No NCCP thresholds, clinical rules, recommendations, protocol dose levels or dose calculations were modified.

The complete security, protocol-publishing, historical regression, global matching audit, GitHub Pages-build, deployable-site and ZIP-integrity pipeline passed. Independent Consultant Oncology and oncology-pharmacy validation remains required.
