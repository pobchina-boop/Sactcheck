Commit summary

Add a constrained clinical scenario interpreter to the regimen engine (v0.54.0)

Commit description

Introduces SACTCheck v0.54.0 with a local constrained scenario interpreter inside the opened regimen assessment engine.

Changes include:

- Adds a Scenario interpreter control within each opened regimen
- Allows a clinician to enter a de-identified clinical scenario in natural language
- Extracts candidate values only for fields already available in the selected regimen
- Supports common blood counts, renal and hepatic results, endocrine tests, ECOG, cycle context, current dose levels, boolean criteria and named toxicity grades
- Maps exact renal values to an encoded protocol band where the regimen uses band selection
- Displays every proposed structured value for clinician confirmation
- Applies only confirmed values to the existing assessment form
- Offers Apply confirmed values and Apply and assess workflows
- Leaves all other fields blank and unassessed
- Warns when possible patient-identifiable information is detected
- Warns when a medicine mentioned in the scenario may not match the opened regimen
- Processes all scenario text locally in the browser without an external model, API call or embedded API key
- Preserves the deterministic SACTCheck assessment engine as the sole source of the encoded protocol result
- Renames the immune panel to Immunotherapy toxicity map
- Adds reliable organ-specific navigation from the immune map to relevant assessment inputs
- Replaces directive immune status wording with decision-support wording

This release does not diagnose, prescribe, clear treatment, create clinical thresholds, calculate a patient-specific final dose or generate a treatment recommendation. It does not send scenario text to an external AI service.

All 382 protocol JSON files remain byte-for-byte unchanged from v0.53.0. No NCCP thresholds, clinical rules, dose levels, recommendations or protocol-dose calculations were modified.

The full security, protocol-publishing, historical regression, GitHub Pages-build and deployable-site validation pipeline passed. Independent Consultant Oncology and oncology-pharmacy validation remains required.
