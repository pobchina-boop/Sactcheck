# SACTCheck v0.49.0 — Haematology Foundation

## Release scope

- Adds a separate burgundy **Haematology SACT** portal alongside the unchanged solid-tumour portal.
- Adds **Plasma-cell disorders** as the first live haematology family.
- Adds five official-source-linked NCCP technical encodings: 00270, 00435, 00416, 00643 and 00275.
- Uses the existing deterministic JSON assessment engine, official PDF action and partial/single-value assessment model.
- Adds route filtering for mixed oral/parenteral and parenteral-only regimens.
- Preserves all 361 pre-existing solid-tumour protocol JSON files.

## Clinical boundary

The five haematology encodings remain pending independent Consultant Haematologist and haematology-pharmacy validation. They are not authorised to prescribe, approve or clear treatment. Clinicians must verify the current official NCCP protocol and apply independent clinical judgement.
