Commit summary

feat(validation): add tissue by tissue clinical review workspace

Commit description

Adds a structured primary clinical validation workspace across all 376 enabled SACTCheck protocols and 451 tissue review contexts.

Shared protocols are reviewed separately for each relevant tissue context so completion in one indication group does not automatically imply completion in another.

Adds thirteen structured review domains covering source identity, indication, regimen components, eligibility, haematology, renal assessment, hepatic assessment, other safety rules, monitoring, supportive care, administration, SACTCheck engine behaviour, output clarity and knowledge base evidence.

Adds explicit review states for confirmed content, not applicable content, required corrections, oncology pharmacy review and consultant review. Primary clinical review is marked complete only when every domain is resolved and no open discrepancy or specialist review request remains.

Adds structured issue logging with severity, domain, notes and resolution state, together with direct access to the current NCCP source and live SACTCheck assessment.

Adds local validation log persistence with JSON export, CSV export, tissue specific export and JSON import so review can continue across sessions without modifying the published clinical protocol library.

Keeps primary clinical review separate from formal independent consultant oncology and oncology pharmacy validation. No protocol rule, threshold, dose action, organ function pathway or protocol JSON file is changed in this release.
