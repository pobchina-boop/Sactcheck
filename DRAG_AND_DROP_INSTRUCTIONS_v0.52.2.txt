SACTCheck v0.52.2 — Integrated Laboratory & Dose Modification

1. Extract the release ZIP.
2. Open the folder named Sactcheck_v0.52.2_FULL.
3. Select everything inside that folder.
4. Drag the selected contents into your existing Sactcheck repository folder.
5. Choose Replace the files in the destination and allow folders to merge.
6. Open GitHub Desktop and review the changes.
7. Commit and push using the included GITHUB_COMMIT_v0.52.2.txt text.

Do not drag the outer Sactcheck_v0.52.2_FULL folder into the repository. Copy its contents.

After deployment, open a regimen with structured dosing data and confirm:
- Bloods and organ function appears near the top of the assessment.
- Clinical toxicities are shown separately.
- Dose & Schedule opens normally.
- Entered values that trigger a dose pathway display Protocol dose modification applies.
- Missing values remain unassessed.

The current official NCCP protocol and authorised prescribing system remain authoritative.
