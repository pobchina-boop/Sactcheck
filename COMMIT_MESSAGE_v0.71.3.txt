SUMMARY
Refine consent layout and surface ICI risks with sourced frequencies

DESCRIPTION
- Combines the pending consent runtime/cache and browser-PDF-viewer fixes into one cumulative release.
- Opens generated consent PDFs in a browser PDF tab rather than automatically saving files to Downloads.
- Refreshes the two-page consent with a restrained colour hierarchy while preserving greyscale print legibility.
- Adds a navy SACTCheck header and visually distinct generic SACT, agent-specific and immune-risk sections.
- Renders regimen medicines in compact bordered agent cards to make better use of the A4 page.
- Fixes checkpoint-inhibitor agent rendering so mapped ICIs no longer show the generic 'Review current medicine-specific material risks' fallback.
- Places the core six immune consent domains directly beneath each mapped checkpoint inhibitor: pneumonitis, colitis/diarrhoea, hepatitis, endocrine toxicity, nephritis and severe skin toxicity.
- Keeps additional uncommon/rare serious immune toxicities in a separate page-2 immune-risk section.
- Seeds selected atezolizumab immune-toxicity frequencies from the current Tecentriq SmPC pooled monotherapy safety population, including nephritis, myocarditis, meningoencephalitis, Guillain-Barre/demyelinating neuropathy, myasthenia gravis, myositis, pancreatitis, severe cutaneous adverse reactions and pericardial disorders.
- Clearly marks percentages as approximate source-specific pooled monotherapy incidences and states that individual risk may differ by indication, combination therapy, route and patient factors.
- Keeps numerical frequency data source-specific rather than applying class-level percentages to other checkpoint inhibitors without an audited source.
- Retains structured NCCP-regimen schedule generation, glyph hardening and the modular + Agent workflow.
- Adds regression tests for ICI core-risk rendering, evidence-frequency metadata, coloured PDF layout, two-page output, cache protection and browser PDF viewing.
- Makes no change to protocol JSON, treatment thresholds, eligibility rules, dose actions or other deterministic clinical assessment logic.
