SACTCheck v0.48.0 — FEASIBILITY STUDY RELEASE

1. Make sure your current SACTCheck folder is backed up or committed in GitHub Desktop.
2. Extract SACTCheck_v0.48.0_STUDY_RELEASE_DROP_IN.zip.
3. Open the extracted folder and select everything inside it.
4. Drag those files and folders into your main Sactcheck repository folder.
5. Choose “Replace the files in the destination” when Windows asks.
6. Restart Live Server and press Ctrl + F5 in the browser.
7. Confirm the header displays “Feasibility study build” and v0.48.0.
8. The first-use study information panel should open automatically. It can be reopened from the header.
