SACTCheck v0.49.0 — COMPLETE REPOSITORY DRAG-AND-DROP RELEASE
==============================================================

This is a complete SACTCheck repository release, not a patch or installer.
It contains the full existing application plus the integrated Haematology Foundation.

HOW TO APPLY
------------
1. Download and extract the ZIP fully.
2. Open the extracted folder named Sactcheck_v0.49.0_FULL.
3. Press Ctrl+A to select everything INSIDE that folder.
4. Drag the selected contents into your existing repository folder:
   C:\Users\Paul\Documents\GitHub\Sactcheck
5. When Windows asks, choose:
   - Replace the files in the destination
   - Merge folders
6. Open GitHub Desktop and review the changes.
7. Commit and push in the normal way.

IMPORTANT
---------
- Do not drag the outer Sactcheck_v0.49.0_FULL folder itself into the repository.
- Copy the CONTENTS of the extracted folder.
- This release does not include a .git folder, so your existing Git history and repository connection remain intact.
- No .bat, PowerShell, Node installer or patch runner is required.
