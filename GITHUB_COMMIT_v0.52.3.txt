Commit summary

Correct field classification and add dedicated ECOG guidance (v0.52.3)

Commit description

Introduces SACTCheck v0.52.3 with corrected assessment-field classification and dedicated ECOG performance-status guidance.

Changes include:

- Fixes a substring-matching defect that placed Pregnant and ECOG performance status in the Haematology laboratory group because the words pregnancy and performance contain the letters “anc”
- Replaces unbounded laboratory substring matching with bounded clinical terms
- Keeps pregnancy, breastfeeding, hypersensitivity and other non-laboratory criteria under Other treatment criteria
- Moves ECOG performance status to Other treatment criteria across the full library
- Adds concise ECOG selector labels and an expandable guide covering ECOG levels 0–5
- Replaces incorrect CTCAE-style ECOG descriptions with functional-status explanations
- Explicitly separates ECOG performance status from CTCAE adverse-event grading
- Adds library-wide regression testing across 6,132 input definitions and 739 ECOG or reproductive fields
- Retains the v0.52.2 integrated laboratory and component-specific protocol dose-modification engine

All clinical protocol JSON files remain unchanged from v0.52.2. No NCCP thresholds, rule conditions, treatment actions, dose bands or protocol-dose calculations were modified.

The full security, protocol-publishing, historical regression, Pages-build and deployable-site validation pipeline passed. Independent Consultant Oncology and oncology-pharmacy validation remains required.
