SACTCheck v0.47.1 drop-in update

1. Keep a backup or commit the current v0.47.0 repository first.
2. Extract the v0.47.1 drop-in ZIP.
3. Select everything inside the extracted folder.
4. Drag the selected files and folders into the main Sactcheck repository folder.
5. Choose "Replace the files in the destination" when Windows asks.
6. Restart Live Server.
7. Refresh the browser with Ctrl + F5.
8. Confirm the release menu shows v0.47.1.
9. Confirm the All catalogue reports 361 canonical NCCP regimens after loading.

Developer JSON preview remains available by adding ?debug=1 to the application URL.
