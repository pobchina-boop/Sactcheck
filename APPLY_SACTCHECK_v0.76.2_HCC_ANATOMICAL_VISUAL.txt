SACTCheck v0.76.2 - HCC anatomical side-effect picture

Why this update exists
v0.76.1 put a small schematic body map inside a largely empty box. It did not match the approved full-height anatomical infographic reference. This update replaces that treatment picture in the app's patient view and printable guide, the public HCC page and the linked PDF guide.

Install / drag and drop
1. Download and unzip the archive.
2. Open your SACTCheck repository at its top level (the folder containing js/, css/, assets/, data/, docs/ and tests/).
3. Drag the archive contents into that folder. Keep the folder structure and choose Replace when prompted. Do not upload the ZIP as a file in the repository; copy its contents.
4. Commit and push. Your existing hosting workflow can then publish the changed files. If the browser still shows v0.76.1, hard refresh the page or check deployment status.

This is consolidated: the archive includes the earlier v0.76.1 agent content, passport and reusable icon files alongside this visual correction. Existing unrelated files in your repository remain in place.

Summary of changes
- Large anatomical illustration with brain, lungs, heart, liver, kidneys, bowel, nerves, muscles and vessels.
- Eight side-effect cards in patient language with clinical terms in brackets and reusable organ icons.
- Purple immune markers, coral bevacizumab marker, clear chest-pain language; jaw symptoms and rare PRES remain called out.
- Updated A4 print page, public HCC page, linked two-page guide PDF; the cycle passport and wallet card continue from the prior update.
- Releases changed to 0.76.2; both included JavaScript tests pass.
