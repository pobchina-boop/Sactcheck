SACTCheck v0.53.0 — Immunotherapy Visual Safety

1. Extract the release ZIP.
2. Open the folder Sactcheck_v0.53.0_FULL.
3. Select everything inside that folder.
4. Drag the selected contents into your existing local Sactcheck repository.
5. Choose Replace the files in the destination and allow folders to merge.
6. Review the changes in GitHub Desktop.
7. Commit and push to origin.
8. Confirm the GitHub Pages deployment completes successfully before testing the live site.

Do not place the outer Sactcheck_v0.53.0_FULL folder inside the repository.
