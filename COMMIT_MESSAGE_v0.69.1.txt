Summary
Fix Sustainability Pages deployment and add regimen metadata foundation v0.69.1

Description
Fixes the Sustainability module 404 by adding sustainability.html to the allow-listed GitHub Pages production artefact.

Strengthens the production-site validator so deployment now fails if the Sustainability page, runtime module or structured sustainability metadata file is missing.

Adds a structured regimen-level sustainability metadata foundation covering route, administration frequency, planned treatment encounters, chair time, ambulatory pump use, cold-chain handling, vial presentation, dose banding, vial sharing, home/local delivery potential and travel-model inputs.

Adds explicit metadata evidence states for catalogue-derived, source-verified, locally verified, modelled, not encoded, not applicable and evidence-required information.

Keeps missing environmental information visible rather than inferring values and does not generate an overall carbon score or environmental traffic-light ranking.

Preserves all NCCP protocol JSON, clinical decision rules, assessment logic, Rule Explorer, NCCP Change Tracker and clinical validation functionality unchanged.
