SACTCheck v0.55.0 — cumulative drag-and-drop update

This package includes all changes from v0.54.0. You do not need to install v0.54.0 separately.

1. Extract the ZIP.
2. Open the folder Sactcheck_v0.55.0_FULL.
3. Select everything inside that folder.
4. Drag the selected contents into the existing Sactcheck repository folder.
5. Choose Replace the files in the destination and allow folders to merge.
6. Review the changes in GitHub Desktop.
7. Commit and push.
8. Confirm that the GitHub Pages workflow completes with a green tick.
9. Test the Clinical scenario interpreter from the main library screen and the Scenario interpreter inside an opened regimen.

Do not drag the outer Sactcheck_v0.55.0_FULL folder into the repository.
