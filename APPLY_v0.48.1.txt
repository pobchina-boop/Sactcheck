SACTCheck v0.48.1 — stability and project-information update

Recommended protected-GitHub workflow

1. In GitHub Desktop, switch to main and pull the latest origin.
2. Create a new branch named: v0.48.1-stability
3. Extract the drop-in ZIP.
4. Copy everything inside the extracted folder into the Sactcheck repository and replace matching files.
5. Commit and push the branch.
6. Open a pull request into main.
7. Wait for Validate and test plus CodeQL to pass.
8. Merge the pull request. GitHub Pages will deploy sactcheck.com automatically.
9. On iPhone Safari, close the old tab and reopen https://sactcheck.com after deployment.

No protocol JSON or clinical decision rule is changed by this release.
