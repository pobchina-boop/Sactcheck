SACTCheck v0.56.0 installation

This is a cumulative repository package. It contains every v0.55.0 and v0.54.0 change.

1. Extract the downloaded ZIP.
2. Open the folder SACTCheck_v0.56.0_FULL.
3. Select everything inside that folder.
4. Drag the selected contents into your existing Sactcheck repository folder.
5. Choose Replace the files in the destination and allow folders to merge.
6. Do not copy the outer SACTCheck_v0.56.0_FULL folder into the repository as a nested directory.
7. Review the changes in GitHub Desktop.
8. Commit and push.
9. Confirm that the GitHub Pages deployment workflow completes successfully.
10. Test the live Clinical scenario interpreter and a Regimen info link after deployment.
