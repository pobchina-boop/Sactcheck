SACTCheck v0.62.0 application instructions

Preferred method

1. Use the full project ZIP as the repository replacement baseline.
2. Copy the contained Sactcheck directory into the working repository.
3. Review the tracker files and GitHub workflow.
4. Run npm test.
5. Run npm run security:check.
6. Run npm run build:pages.
7. Run npm run security:site.
8. Commit using the separate summary and description in GITHUB_COMMIT_v0.62.0.txt.
9. Deploy through the existing GitHub Pages workflow.

First source capture

1. Open the Actions tab in GitHub.
2. Select NCCP Change Tracker.
3. Choose Run workflow.
4. Review the generated pull request before merging.
5. The first successful run captures remote PDF and extracted text fingerprints. It does not update clinical rules.

Drop in method

1. Extract the drop in ZIP over an existing v0.61.0 repository.
2. Preserve the directory structure and replace matching files.
3. Run the validation commands listed above.

No protocol JSON file is changed by this release.
