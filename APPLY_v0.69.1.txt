SACTCheck v0.69.1 — Sustainability Deployment + Metadata Foundation

ROOT CAUSE OF THE 404
The production GitHub Pages workflow builds an allow-listed _site directory. sustainability.html existed in GitHub but was not included in the top-level allow-list, so the deployment succeeded while the page itself was omitted.

APPLY
1. Extract the ZIP.
2. Drag everything inside it into the root of the existing SACTCheck project.
3. Choose Replace files in the destination.
4. Run: node tests/sustainability-v0691.test.js
5. Then run the normal full regression suite if desired: npm test
6. Commit and push to main.
7. GitHub Pages will rebuild automatically.
8. When the Pages workflow is green, hard-refresh the live site and open Sustainability again.

No protocol JSON or clinical decision-rule files are changed.
