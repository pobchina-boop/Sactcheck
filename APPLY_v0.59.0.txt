SACTCheck v0.59.0 — application instructions

FULL PROJECT
1. Extract SACTCheck_v0.59.0_full_project.zip.
2. Replace the contents of your local Sactcheck repository with the extracted Sactcheck folder contents.
3. Review the changed files, then commit and push through the usual GitHub workflow.

DROP-IN UPDATE
1. Extract SACTCheck_v0.59.0_drop_in.zip.
2. Copy the contained Sactcheck folder over the existing v0.58.1 repository root and allow matching files to be replaced.
3. Do not delete unrelated repository files.

VALIDATION
From the repository root, run:
  npm run audit:organ-function:v0590
  npm run test:v0590
  npm test
  npm run security:check
  npm run build:pages
  npm run security:site

SAFETY
The 74-record organ-function reconciliation is internally tested but remains pending independent consultant oncology and oncology-pharmacy validation. The current official NCCP protocol and local governance remain authoritative.
