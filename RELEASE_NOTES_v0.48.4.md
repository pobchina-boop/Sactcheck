# SACTCheck v0.48.4 — Oral anti-cancer service and privacy wording update

## Summary

This release adds an **Oral anti-cancer medicines** category across the existing tumour-site catalogue and replaces the terms **patient-agnostic** and **hypothetical** in the active user interface.

## Changes

- Added an Oral anti-cancer medicines option to the treatment-category filter.
- Added an Oral anti-cancer medicine badge to matching regimen cards.
- Added tumour-site landing-page counts and shortcuts for oral regimens.
- Added route-aware classification covering oral targeted therapy, PARP inhibitors, CDK4/6 inhibitors, oral cytotoxic agents and relevant endocrine therapies.
- Included mixed regimens containing a substantive oral anti-cancer component, such as XELOX.
- Excluded IV regimens that contain only an oral supportive medicine such as prednisolone.
- Added oral-service search terms and common shorthand including OAM, OACM, oral SACT, palbo, ribo, abema, olap, nira and ruca.
- Replaced the landing-page Patient-agnostic card with No patient-identifiable information required.
- Removed hypothetical wording from the active interface, welcome panel and quick-start material.
- Retained explicit instructions not to enter patient-identifiable information.
- Made no protocol JSON, NCCP threshold, dose-modification or assessment-rule changes.
