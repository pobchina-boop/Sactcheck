# SACTCheck v0.43.0 — Complete Gynaecology Library

## Scope

This release completes the current NCCP Gynaecology SACT catalogue as active encoded assessment protocols.

## Inventory

- 48 active Gynaecology protocols
- 28 new protocol files and 20 reconciled canonical/shared protocols
- No Gynaecology placeholders or draft cards
- 308 distinct protocols across the complete SACTCheck library

## Clinical areas

- Cervical cancer and chemoradiation
- Endometrial cancer
- Ovarian, fallopian tube and primary peritoneal cancer
- Gestational trophoblastic neoplasia
- Ovarian germ-cell tumours
- Immunotherapy, PARP inhibitors, anti-VEGF therapy and later-line chemotherapy

## Platform standards

- Single-entry partial assessment
- Missing values remain unassessed and non-blocking
- Actual ALT, AST and bilirubin input with automatic local ULN calculation
- Protocol-specific renal bands, with exact GFR retained for carboplatin/Calvert dosing
- Optional immunotherapy-only endocrine bloods
- CTCAE grade explanations beside toxicity controls
- Searchable common/trade names and official NCCP PDF links

All clinical encodings remain pending independent Consultant and oncology-pharmacy validation before formal deployment.
