# Breast patient logistics and timeline references

Received from Paul O’Brien on 16 October 2026; supplied to him by a consultant.
Retained originals: “Breast chemo diagrammes.pptx” (35 slides) and “CDK4-6 blood monitoring.pptx” (10 slides), in the project’s Breast Reference Materials folder.

Use these when developing breast patient information: treatment sequence, cycle/visit diagrams, surgery and maintenance transitions, oral treatment/rest periods, blood tests and ECG logistics. Preserve short visual explanations with optional detail and no required date entry.

These are reference material for adaptation, not validated universal protocols. Check each indication, medicine, duration and monitoring schedule against the current NCCP/SmPC and the treating centre. The monitoring deck includes Galway-area home-nursing arrangements; do not present these as CUH arrangements. Record local provenance explicitly. Confirm consultant attribution and permission before publicly reproducing original slides. The original decks are not included in the public website or release ZIP.
